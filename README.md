# truyen
🧪 Cách thêm một truyện mới (rất dễ)
Tạo thư mục trong stories/ với tên slug (viết thường, không dấu, ví dụ co-gai-xuyen-khong).

Tạo file story.json trong thư mục đó theo mẫu (có thể copy từ truyện khác).

Tạo thư mục chapters/ bên trong.

Thêm các file .txt đánh số theo id chương (ví dụ 1.txt, 2.txt...).

Thêm một dòng vào stories/stories.json (lấy id mới, slug vừa tạo, genre, status, lastUpdate).

Xong! Không cần sửa code JS, không cần build.
